# Responsive Personal Blog Website

A clean and minimal personal blog template built using **HTML**, **CSS**, and **JavaScript**.  
This project is designed for writers who need a **simple and responsive platform** to publish and manage posts — without the complexity of heavy CMS platforms like WordPress.

---

## 🚀 Features

- ✅ **Responsive & Mobile-Friendly UI**
- ✅ **Dynamic Posts Rendering from Local JSON / JavaScript Array**
- ✅ **Search Functionality**
- ✅ **Popular Tags Filter**
- ✅ **Recent Posts Section**
- ✅ **Modal View for Full Blog Content**

---

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| HTML5 | Page Structure |
| CSS3 (Custom + Flex/Grid) | Styling & Responsive Layout |
| JavaScript | Dynamic Rendering, Search & Modal Interactions |

│── styles.css # Global Styling

│── README.md # Project Documentation

## 📌 How to Run the Project

Just **download or clone** the repository and open `index.html` in any browser.
```
git clone https://github.com/Dev-Joshi2004/responsive-blog-website
cd responsive-blog-website

```
